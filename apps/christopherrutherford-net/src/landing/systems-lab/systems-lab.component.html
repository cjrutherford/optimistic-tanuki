Inside the workspace

Systems Lab

The repository connects customer-facing applications to shared platform code, services, and delivery tooling. Each layer has a clear home in the Nx workspace.

  1. Application experiences

    Angular clients live in apps/. They bring together the screens and workflows for each product.

  2. Shared Angular libraries

    Reusable components come from libraries such as common-ui. Theme models and styles provide shared tokens, while model and contract libraries define the data applications exchange.

  3. Gateway and NestJS services

    The Gateway handles HTTP, SSE, and WebSocket entry points. It routes work to NestJS services, which communicate with one another over TCP message patterns.

  4. Data and security

    Service-owned persistence sits alongside shared database, storage, encryption, authentication, and permission libraries.

  5. Nx and Docker delivery

    Nx organizes projects and build tasks. Docker Compose supports local stacks, and the repository also contains Kubernetes deployment configuration.
