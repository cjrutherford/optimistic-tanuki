Reclassification runs

A run applies a mapping version to stored listings. Start with a dry run: it shows every category change and writes nothing. An apply names the plan of a completed dry run, needs a typed confirmation, and stops with no changes if the data has moved since the plan. A completed apply can be rolled back; rows an operator has since changed by hand are left alone.
