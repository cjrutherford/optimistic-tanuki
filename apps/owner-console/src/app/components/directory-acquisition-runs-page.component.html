Acquisition runs

Every acquisition run is recorded here with its progress per town or source unit. Runs are made by the local stage scripts; this page watches them and records requests. Resuming or retrying never starts work from here: it shows the command to run locally. Real acquisition is not authorised and nothing acquires automatically.
