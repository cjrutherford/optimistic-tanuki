# UI Playground

Every Optimistic Tanuki UI library in one Storybook, together with the repository documentation and generated API reference. Use the **Personality** and **Mode** toolbars to preview any component in any of the twelve personalities, light or dark.

Each library's stories come from that library's own Storybook configuration (`libs/<lib>/.storybook/main.ts`), so what you see here is exactly what the library's Storybook shows.

## Where to start

- **Read the docs first.** Migration notes, architecture, runbooks, and package guidance: [Documentation](?path=/docs/docs-overview--docs) and the [API Reference](?path=/docs/docs-api-reference--docs).
- **Start with core components.** Buttons, cards, modals, tables, and other reusable primitives live under **Common UI**.
- **Validate themes and shared states.** The [Validation Board](?path=/story/playground-validation-board--board) puts one component from each library on a single page.

## Quick start

```bash
pnpm add @optimistic-tanuki/common-ui @optimistic-tanuki/theme-lib
```

All UI libraries are standalone Angular components. Give the app its personality with `provideProductTheme('<app>')` in `app.config.ts`, add `libs/theme-styles/src/lib/base.scss` ahead of the app stylesheet, then import the components you need.
