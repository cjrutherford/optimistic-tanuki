# @optimistic-tanuki/payments-ui-data-access

Generated Angular client for the gateway payments routes (`/api/payments/*`,
orval `payments` tag). Do not edit `src/generated/` by hand. Only the
donations routes currently have UI callers; the rest are generated for
documentation and future adoption (Track B only until then).

```bash
pnpm run get-openapi
pnpm exec nx run payments-ui-data-access:generate
```
