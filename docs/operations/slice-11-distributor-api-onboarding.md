HAI has no approved API accounts or credentials for CDW, Newegg Business, Amazon Business, or Dell OEM as of 2026-09-28. Current code and verification state:

Amazon Business API configuration reads these environment variable names from the API process:

```text
AMAZON_BUSINESS_CLIENT_ID
AMAZON_BUSINESS_CLIENT_SECRET
AMAZON_BUSINESS_REFRESH_TOKEN
AMAZON_BUSINESS_USER_EMAIL
```

No credential values are present in this repository, and none of these accounts is currently set up for HAI. Do not run a live supplier acceptance test or treat mocked adapter tests as proof of live access until an approved account and its credentials are provisioned through the deployment secret manager. Do not add credential values to source control.

## Official provider documentation and access paths

- CDW: [Price and Availability API portal](https://portal.apiconnect.cdw.com/apis), [portal FAQ](https://portal.apiconnect.cdw.com/faq), and [eProcurement catalogs](https://www.cdw.com/content/cdw/en/services/eprocurement-and-custom-catalogs.html). Confirm with CDW which account, subscription, endpoints, catalog, pricing agreement, and rate limits apply to HAI.
- Amazon Business: [Product Search API overview](https://docs.business.amazon.com/docs/product-search-api-overview) and [official onboarding flow](https://docs.business.amazon.com/docs/onboarding-overview). Access, application approval, customer authorization, and permitted catalog use must be confirmed through Amazon's onboarding for HAI's account.
- Dell OEM: [Dell Premier Catalog Pull API v2](https://developer.dell.com/apis/42342cfa-92ad-48f2-818c-b9922ac24e8e/versions/2.0.0). Confirm the customer-specific integration, authorization, catalog contract, and response schema with Dell's integration team.
- Newegg Business: obtain buyer-side API or contracted-feed documentation and credentials directly from Newegg Business. The public [price](https://developer.newegg.com/newegg_marketplace_api/item_management/get_item_price/) and [inventory](https://developer.newegg.com/newegg_marketplace_api/item_management/get_item_inventory/) pages document seller listing APIs.

For each provider, record the account owner, approved production and sandbox access, SKU/catalog scope, credential delivery and rotation procedure, rate limits, and whether the agreement permits storing price and availability snapshots for 30-day quotes. Do not enable firm owner-issued quotes from a provider until its connector has been checked against that provider's authorized HAI account and catalog.

## Connector implementation status

- Amazon Business keyword search is wired to the Product Search API and stores normalized results with `live-api` provenance. Configure `AMAZON_BUSINESS_CLIENT_ID`, `AMAZON_BUSINESS_CLIENT_SECRET`, `AMAZON_BUSINESS_REFRESH_TOKEN`, and `AMAZON_BUSINESS_USER_EMAIL` in the deployment secret manager. The owner search fails closed until all four values are present. It requests the documented `InStockOnly` filter and still requires a current USD offer before quote issuance.
- Dell Premier has an OAuth and Catalog Search adapter with an injected catalog normalizer. HAI must supply its Dell-provisioned response schema and mapping before the connector can be enabled.
- CDW and Newegg Business do not yet have a buyer-side live adapter in this repository. Newegg's public Marketplace Seller APIs are not a substitute for a buyer sourcing entitlement.
- No provider currently has HAI credentials configured. Adapter contract tests do not count as live supplier acceptance. File-imported offers remain visible for review but are blocked from firm customer quotes.
