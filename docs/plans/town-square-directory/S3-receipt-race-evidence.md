# S3 receipt race evidence

2026-11-04. Five deterministic race/failure checks passed on the current uncommitted source using fresh, migrated Social and Directory PostgreSQL databases, a rebuilt Social TCP service, and the actual Directory reconciler and receipt HTTP handler. This is targeted test evidence, not full release acceptance or proof of production deployment behavior.

## Observed outcomes

| Scenario                                                                                     | Outcome                                                                                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Duplicate paused before Directory event lock; Social ACK and cleanup complete before release | Initial apply returned `applied`; Social ACK returned `deleted`; cleanup returned `retired`; released duplicate returned `retired` and no receipt existed.                                                                                                                                                              |
| Apply paused immediately after obtaining event transaction lock; cleanup races               | Independent `pg_try_advisory_xact_lock` returned false; cleanup remained unresolved at the barrier. After release apply returned `applied`, cleanup returned `pending`, and one receipt remained. ACK and subsequent cleanup retired it.                                                                                |
| Social outage and incorrect event/community pair                                             | A real connection to an unused Social port and an incorrect UUID each caused apply to reject without a receipt. After valid apply, both outage and wrong-pair cleanup rejected and the receipt remained.                                                                                                                |
| Post-commit receipt response race                                                            | The HTTP handler was paused before its receipt query after apply committed; receipt existed, valid Social ACK deleted the event and cleanup retired the receipt. Releasing the query produced HTTP **503**, with no receipt left. The response is retryable; an actual retry was not exercised in this particular race. |
| Concurrent admission                                                                         | With capacity 2, three distinct pending Social events applied concurrently: two succeeded, one rejected with capacity error, and exactly two receipts existed.                                                                                                                                                          |

The run reported `ALL PASS`. Barriers did not assert public geometry or execute the full worker retry loop, and the test driver invokes cleanup directly rather than exercising the main process's periodic sweep. The capacity check did not test subsequent admission after a slot was freed. These limits should not be inferred as passing checks.

## Cleanup

The run removed its `s3race-test-social` and `s3race-test-db` containers, `s3race-test-net` network, and `s3race-current-social` image; follow-up Docker listings for these names were empty. The disposable databases were container-local. Existing images and services were left in place. Temporary frozen source, manifest, harness, build and migration logs remain under `/tmp` for inspection; no application source, provider, production service, or commit was changed by this test.
