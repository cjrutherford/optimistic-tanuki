# S10 locked town boundaries

Researched with Census TIGER 2026 only (www2.census.gov, digest-pinned archives). Where Census has no matching entity, nothing is installed and the town is listed with a suggested action. Nothing else (OSM, Overture) was used.

Install the 18 locked boundaries with `scripts/local-directory-locked-boundaries.cjs` (use `--dry-run` first). A locked town is never replaced by the sweep, the register re-reconcile or the recovery resets; only a reviewer decision can change it.

Most of these towns failed automatic matching because the Social reference point is wrong. The confidence below therefore rests on a unique name and state match in Census, not on the Social point. Social coordinates for these towns should be corrected (Seguin is a longitude typo, Hatteras a latitude 0.47 degrees off, Cedar Key lands in the Gulf).
