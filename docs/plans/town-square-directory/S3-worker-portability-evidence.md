# S3 worker target portability evidence

On 2026-11-04, the worker Nx test target changed from GNU-only `timeout --kill-after=5s 180s` to the BusyBox/GNU-compatible `timeout -k 5s 180s`. Both preserve a 180-second deadline and five-second TERM-to-KILL grace. The old option failed in the Alpine builder (BusyBox 1.37.0); a TERM-ignoring process was forcibly killed using the short option on the Debian host and Alpine builder (exit 137).

An uncached `NX_DAEMON=false NX_ISOLATE_PLUGINS=false NX_NO_CLOUD=true pnpm exec nx test directory-worker --skip-nx-cache` ran in `s3live-directory-builder:latest` (Node 24.22.2, Alpine 3.24.3), mounting the current directory and worker sources. It passed 18 tests, failed 0, skipped 3. The skipped tests are the opt-in Docker-driven ACL workload, AOF recovery, and worker-restart tests; Docker was not exposed to the builder. The run used a fresh disposable PostGIS 17 database migrated through `directory:typeorm:migration:run`, and a disposable Redis with two prefix-restricted ACL users and an admin account for fault injection. The first run exposed an incorrectly named fixture user; a subsequent run exposed synthetic data left by that failed run. The successful run used corrected users and a freshly recreated fixture database. Nx reported a flaky task because of those earlier failures.

A separate disposable Compose project extended the checked-in `directory-migrate` service, used the same Alpine builder and current directory source, and connected to a PostGIS container started only after its first migration attempt failed. The service logged the failed attempt and then completion, exited 0 and had zero container restarts. This validates a delayed external database in the isolated Compose arrangement, not deployment-specific DNS, credentials, or restart behavior.

Only synthetic test records and disposable containers/network were used. No provider calls, POC imports, production databases, or shared services were used or modified. This evidence does not establish provider ingestion or production deployment readiness.
