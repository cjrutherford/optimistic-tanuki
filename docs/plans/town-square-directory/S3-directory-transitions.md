# S3 Directory local authority transitions

The operator must externally fence every old writer and serving process before beginning recovery. The confirmation flag records that operator assertion; Directory cannot detect or certify the fence or verify Social's identity. Supply the fresh Social source epoch, activation ID, owner and positive decimal Social generation to `recovery-begin-operator --confirm-external-fence`. Directory serializes begin and traversal on the authority advisory lock, rotates its recovery epoch, increments its generation and atomically resets the checkpoint, marks town geometry pending and blocks provider work. Receipts are retained; the Social outbox is untouched. A matching retry returns the current checkpoint without resetting progress. Legacy checkpoints and stale or conflicting identities fail closed. A new transition requires both a changed Social epoch and activation ID and an increasing Social generation; Social and the operator must guarantee those values are authentic and fresh, including across restores. The local six-field checkpoint alone cannot prove historical UUID uniqueness or detect an independently restored Directory database.

Traversal requires all six fields and proceeds blocked → social → directory → traversed. Traversed is not enabled: coordinated activation, serving, and ACK remain unimplemented and the external fence must remain in place. No schema change was needed.

Verification: a disposable PostGIS 17 container received the full Directory Nx migration chain, and the uncached `directory:test` target ran against isolated databases cloned from that template: 30 passed, 8 skipped, 0 failed. The real database transition test covered fresh and repeat recovery, idempotent retry after traversal, stale/legacy identities, rollback, concurrent authority locking, pending geometry and provider work, privacy withdrawal, and receipt preservation. The Directory Nx build passed with current Directory, worker and Social contracts mounted into the existing builder image. The test Social census/snapshot source is simulated; cross-store coordination, actual Social outbox behavior, proof integration, and production fences remain unverified. The disposable database container was removed.
