# S3 isolated Compose operating evidence

**Status: evidence for accepted local, pending-only S3.** On 2026-11-06, two disposable PostGIS 17 databases and isolated Compose projects exercised pending-only Social, Directory and worker processes. No provider call, public release, production deployment, or change to the shared Social database occurred.

The Compose projects used the checked-in Directory service definitions with temporary overrides. Social used the current built artifact over a previously available Social image; Directory and worker images were assembled from their current generated artifacts and dependency manifests. The Social and Directory migrations ran separately through their owning Nx targets against fresh databases, and the Compose migration service was a no-op in the main experiment. Separately, the checked-in Directory Dockerfile's builder stage and Compose migration command ran successfully against another fresh database, applying 13 migrations. The final checked-in production images were not built for this experiment.
