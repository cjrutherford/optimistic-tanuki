# S10 source-capability disposition ledger

Status: **draft for S10 review; no capability here is accepted by this file.** It maps every row of the [S0 capability ledger](S0-capability-ledger.md) and every bullet of [plan section 3](../2026-11-04-town-square-business-directory.md) to a target anchor and one disposition. It is a map of evidence, not a new test run: nothing was executed to write it. Target anchors were confirmed by reading code at the cited `file:line`.

**Disposition vocabulary.** `integrated`: built in the target and proven on the real stack. `integrated (local scope)`: built, and proven only on the local Docker stack with the local evaluation data and with publication paused; not production, not public. `deferred`: intentionally not built, with a rationale. `open/blocking`: required for the full-capability objective and not met. `unknown`: not enough evidence found to place it.

**Standing constraints that shape the ratings.**

- Real provider acquisition is unauthorized: `ACQUISITION_AUTHORIZED = false` (`apps/directory/src/acquisition-run.ts:42`). No live upstream provider request has been made by the target. Staged Overture artifacts were loaded by operator-local scripts.
- Geoapify is denied for public display and export (`apps/directory/src/export-job.ts` `NON_EXPORTABLE`; `public-export.ts`). Since S10 D4 it is authorized for private enrichment only (`PRIVATE_ENRICHMENT_PROVIDERS`); see [s10-atp-geoapify](s10-evidence/s10-atp-geoapify.json). S10 D8: Geoapify is enabled with its own $25 (2500 cent) monthly hard stop on a separate ledger, a 50 lookup daily cap, batch 5, 30 day retention (owner-confirmed) and key redaction. The 1 cent per lookup cost is a conservative figure; the pricing page was unreachable, so the price is unverified. See [s10-d7-d8-d12](s10-evidence/s10-d7-d8-d12.json).
- AllThePlaces is also a standalone CC0-1.0 provider since S10 D3 (pinned official run, `alltheplaces.ts`, `alltheplaces-acquisition.ts`, worker `alltheplaces-snapshot.ts`), separate from the copy Overture carries ([s10-atp-geoapify](s10-evidence/s10-atp-geoapify.json)).
- Publication is paused and the local sample has not passed the full-frame quality review ([S5 caveats](S5-public-contract.md#remaining-caveats)). Every "integrated (local scope)" row is therefore not a public or production claim.
- Directory data is a private/staged Overture-derived set (182,277 screened listings over 133 towns plus the 4,850 pilot rows without provenance, which S10 D12 retired (valdosta-ga and alexandria-va were re-acquired with provenance and now export 200), per [SLICE-STATUS](SLICE-STATUS.md)). This ledger makes no "all businesses" or "complete coverage" claim, and none is supported.
- The S7 address auto-approval section 12 decisions belong to the owner ([S7-address-review-auto-approval.md](S7-address-review-auto-approval.md)).
- Evidence labels: **live** means observed on the running local stack; **fixture/scratch** means disposable database, mocked, intercepted or unit proof only. Fixture or scratch proof is never counted as live.
- No file in `docs/release-readiness/DEFERRED-FEATURES.md` mentions the directory (searched for `director`, `business directory`, `town square`: no hits), so no deferral below is recorded there yet. Plan section 4 S10 requires the deferrals to be synchronized into that file.

Link convention: links are relative to this directory. Test names are in `apps/directory/test/` unless a path is given. Gateway controllers are in `apps/gateway/src/controllers/directory/`.

## 2. Worker queues, processors and injection

The target worker is not a BullMQ topology. `apps/directory-worker/src/queue.ts` is a custom Redis hash queue (single-record leases), and the live runtime mode is `register-pending-v1`, which delivers Social register events and does not run provider stages ([S9 drill](s9-evidence/restart-outage-drill.md)). Export, withdrawal and the binding sweep run in-process in the Directory service or worker. The POC stage pipeline is therefore not ported as queues; acquisition is operator-local scripts.
