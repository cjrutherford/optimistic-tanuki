## Findings and minimum release checklist

1. **P1 — mobile map usability, local acceptance gate.** Prior review reported clipping after resize; `map.component.ts:622-653` observes size and invalidates Leaflet, but this does not prove fitting/visibility after a viewport change. Reproduce on current head at mobile width with a populated town, test desktop-to-mobile resize and fresh mobile load, and fix the actual cause in the shared map component; verify markers, popup, keyboard focus and controls. No current Jacksonville mobile capture establishes the result.
2. **P1 — production gate, owner.** Complete the owner-assigned S9 production credentials/ACL/TLS, backup and restore, external alerting and monitoring, cost reconciliation, outage/retention drills, production-scale qualification and deployment/rollback evidence; identify deployed image SHA and run real public list/detail/map and privacy checks. Obtain the plan's release approval. Production is explicitly deferred in S10; this review does not substitute for it.
3. **P2 — map can hang if its external CSS fails.** `apps/local-hub/src/app/components/map/map.component.ts:90-117` calls `initMap` only after a stylesheet `load`, with no `error` resolution or error state. A blocked CDN can leave the map loading indefinitely. Add bounded error handling and an accessible fallback/retry; test a failed stylesheet request. The list remains a separate path; runtime failure was inferred from code, not injected here.
4. **P2 — category discoverability.** `business-directory.component.ts:156-159` computes filter choices from loaded listings only. A category occurring on a later page is absent until those pages are loaded, and filtering can further narrow choices. Provide a rights-safe server facet or a clearly complete taxonomy, preserving the selected value, and test a category that occurs only on a later page. Scope to directory API and shared filter as appropriate.
5. **P2 — reconcile data and acceptance evidence.** Sample source-to-public lineage and publication/review reasons for Jacksonville and San Antonio, including withheld and sensitive addresses, rights, Geoapify exclusion, corrections/withdrawal and export. Quantify address/coordinate availability across pages and towns without promising complete coverage. Reconcile `S10-acceptance-scorecard.md` and `S10-capability-ledger.md`: the ledger's summary says two live auto-approvals and completed pilot swap while its open-items text and scorecard say otherwise. Verify underlying dated evidence before changing status; the PR description is also older on normalization and Geoapify budget (D27/D30). Assign remaining duplicate queue and review capacity to an operator.
6. **P2 — release evidence for interaction and scale.** Exercise filters, load-more, cursor restore, back navigation and popup detail links against a matching current build; check loading, empty, API/CDN failure and screen-reader/keyboard behavior. Measure dense towns and repeated load-more/resize before selecting a marker clustering or incremental rendering fix. Confirm results in both local and deployed environments when deployment is authorized.
