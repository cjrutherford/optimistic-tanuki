## OSS stack

### Core services

- Files & collaboration — Nextcloud
- Photos — Immich
- Media — Jellyfin
- Documents — Paperless-ngx
- Passwords — Vaultwarden

### Platform and operations

- Linux (Debian/Ubuntu)
- Docker Compose
- Reverse proxy & TLS
- Remote access — WireGuard
- Backups — Restic
- Monitoring — Uptime Kuma
- Storage and health checks
