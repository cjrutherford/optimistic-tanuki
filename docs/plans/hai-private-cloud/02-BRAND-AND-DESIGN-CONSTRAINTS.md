# Brand and Design Constraints

## Visual language

Use the existing HAI design system. Colour comes from the user's theme and
personality variables, never from literals (D008). The palette below describes
the intended feel, not values to hard-code.

- Deep teal / charcoal background
- Cyan primary accent
- Restrained orange secondary accent
- Strong white headline hierarchy
- Panel shape (radius, outline) from the active personality; the default
  `foundation` is square and borderless (D012)
- Limited glass effects
- Restrained glow
- Generous negative space
- Realistic technology imagery where imagery helps

## Do not

- Create a second visual identity for private cloud
- Overuse glow, gradients, decorative rings, or generic AI-tech ornamentation
- Crowd sections with excessive copy
- Use cross imagery or church-specific religious symbols
- Use the word `dev` in the logo

## Brand mark

Use the favicon-style `HAI` mark without `dev`. The owner supplies it (D013).

## Terminology

Use **Faith groups**, not **Churches**.

## Layout expectations

- Strong hierarchy
- Clear CTA per major page
- Mobile-safe typography
- No text overflow
- Long email address must never overflow
- Reuse current spacing and card patterns
