# App Configurator account-export policy (O02)

O02 is delivery 2 in the fixed release sequence. Policy, capture and job integration belong to this delivery. Its acceptance evidence is recorded in the O02 finding and receipt; this policy alone does not establish runtime acceptance.

Capture selects a row only when its recorded account ID matches the authenticated account and its recorded profile ID belongs to the captured current Profile identity set. The request app ID authenticates the operation; it does not filter account-wide rows by app scope. Matching today's identity binding does not prove historical authorship, consent or present authority. Every receipt retains `attribution: recorded-unverified` and `consent: not-inferred`.

| Source                 | Selection and parent boundary                                                                                                                                                                      | Projection                                                                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| AppConfigurationEntity | Recorded `ownerUserId` and captured `ownerProfileId`; the composite instance/workspace/scope parent must also carry that recorded owner pair. A selected row with an invalid parent fails capture. | Registration IDs, bounded name and scope, nullable credential-free DNS domain, active flag, known access policy, positive revision and timestamps. |
| AppInstanceEntity      | Recorded `ownerUserId` and captured `ownerProfileId`.                                                                                                                                              | Its eight registration and lifecycle fields. Workspace identity is an opaque reference.                                                            |
| AppMembershipEntity    | Recorded `userId` and captured `profileId`; validate the composite parent without exporting its owner or content.                                                                                  | The subject's own ten membership fields, including recorded role and status. Membership in another person's app is allowed as a personal receipt.  |

Historical lifecycle states are included; an inactive or revoked state is not silently discarded. Shared app ownership does not authorize access to other members. Parent IDs contextualize the subject's receipt and are never traversed into shared Workspace content or counterpart configuration.

Configuration `description`, `landingPage`, `routes`, `features`, `theme`, `manifest` and `release` are excluded. Their untyped shared prose and JSON can contain counterpart content, credentials or operational payloads; row attribution is not field-level provenance. Capture neither serializes those values nor fetches referenced pages, media or services. Exclusions remain visible in the disposition inventory; O02 does not claim portable copies of shared application content.

The machine-readable inventory covers all three registered entities, their columns and composite parent relations, plus migration bookkeeping, process output and configuration inputs. Migration bookkeeping is excluded as operational metadata. External process output is shared and excluded; deployed log sinks and retention are not established here. Configuration inputs are opaque and excluded because they can contain credentials. The config loader does not log its resolved credentials.

The owner uses the shared PostgreSQL capture driver, captured Profile identities and a consistent read-only transaction. SQL projects bounded allowlisted fields before buffering, uses deterministic keyset pages, and rejects malformed selected data rather than truncating it into a success. Timestamps preserve stored microseconds. The leased snapshot wrapper supplies bounded reads, integrity verification, expiry and cleanup; Authentication appends App Configurator after Workspace and cleans captures up in reverse order.

The account-wide job remains incomplete with no artifact URL. O02 does not establish download, deletion, external-flow or production release qualification.
