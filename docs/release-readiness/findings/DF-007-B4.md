# DF-007 B4: bounded Social preview

B4 is locally verified on 2026-10-18. The independent source review and CI-aligned gates passed, and the clean private Authentication/Profile/Permissions/Social run passed 21/21 tests in two suites. **DF-007 and RR-11 remain open; this checkpoint is an internal diagnostic preview, not an account export or deletion workflow.**

The internal Social participant validates the account subject before Social repository reads and obtains profile IDs only from Profile’s authenticated, bounded resolver. It projects selected fields from account-and-profile-owned posts, comments, reactions and votes, attachment metadata attached to verified owned posts, and Poll definitions directly authored by the account/profile pair. Returned rows are rechecked. Foreign post/comment bodies, moderation fields, Poll vote arrays, attachment paths, Link URLs and arbitrary SocialComponent JSON are omitted. The participant is always partial because identity pages and dataset reads are live and unfenced; an empty or final page does not prove a complete inventory.

Poll has no verified Post association in the current schema. Its entity relation declarations have no join columns, the migrations add no Poll `postId` or Post `pollId`, and no association table exists. B4 therefore queries Poll definitions by stored `userId` and trusted `profileId`, returns the owned profile reference, and never claims a Post association. It omits the multi-account `votes` array and always reports `poll-post-association-unverified` and `social-poll-vote-history-uncovered`. Historical/internal-RPC authorship integrity remains unverified.

The preview applies UUID paging, profile/row/time caps, selected-column projections and string/serialized-output limits. These bound accepted rows and output, but selected database text and arrays are materialized before their string/byte checks; they do not bound database-read memory. The response timer also does not prove cancellation of underlying SQL. Streaming/read-byte bounds and verified query cancellation remain open. No portable media bytes are included.
