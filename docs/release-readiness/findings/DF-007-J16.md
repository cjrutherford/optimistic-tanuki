# DF-007 J16 — Social entity registration parity

Status: locally verified registration repair. DF-007 and RR-11 remain open.

Nest repository providers registered a different set of 30: they included those elections but omitted GuardianContentAudit, GuardianPublishedAssetGrant and ContentModerationAction. This mismatch prevented the source inventory from serving as trustworthy owner coverage.

The new test failed on the missing election registrations before the repair. It now passes, comparing exact sets across both datasources and repository providers and building real TypeORM metadata for all 33 entities without a database. Social production build and lint passed. Logs are retained under `.runtime-artifacts/account-rights/finish-sequence/social-entity-parity/`.
