## Capture and failure boundary

The owner component reuses the shared Profile snapshot identity client, owner emitter and spool verifier. It validates the capture lease, copies the Profile descriptor, scopes identities in a temporary table, and reads under a repeatable-read, read-only transaction. Explicit field projections bound database values before buffering and normalize timestamps as UTC. Captures are limited to 45 seconds, 100,000 records and 64 MiB, with 200-row database pages. Malformed records, consumer failures, lost leases and deadlines prevent terminal success. Temporary state and connections are cleaned before completion; cleanup failure quarantines the reader.

The new owner service is not registered in the production module or exposed through an RPC handler in J24. J25 owns that integration. The existing partial preview is not promoted to a complete export.
