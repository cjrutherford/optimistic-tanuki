# A05 — authorized export downloads

**VERIFIED LOCAL OT/TS, 2026-10-24.** The production Gateway download controller and Authentication capability service were exercised through real HTTP, JWT/cookie authentication, the Authentication database and encrypted artifact files. U01 still owns the public settings/create/status controls.

Downloads derive account and app from the authenticated Gateway context. Authentication verifies the current session, exact job/attempt and current private descriptor before opening and on every read. Capabilities remain inside the services, bind to a session hash, last at most 60 seconds and never outlive the artifact. Opening reservations enforce two capabilities per account and eight per process. Plaintext verification spools are immediately unlinked; revocation, close, expiry and shutdown close them, with failed cleanup retained for retry.

The Gateway streams at most 64 KiB per RPC and waits for response backpressure. TAR MIME, attachment filename, length, no-store caching, nosniff, ETag and single-range responses are server-owned. Malformed offsets/base64, downstream revocation, invalid ranges and interrupted streams fail closed and release the capability. No storage path or private descriptor reaches job status.

Nine focused capability tests and twelve real Nest/HTTP controller tests passed. A07's twelve-service run additionally verified cookie and bearer downloads, exact bytes and headers, range slices, foreign-account/app denial, missing credentials, and revocation of a real stored session after a capability had opened. See [A07](DF-007-A07.md) for the runtime receipt and limits.
