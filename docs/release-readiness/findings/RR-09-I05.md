**Status:** PLANNED — prior broad axe scans and the final I03 live diagnostic reproduce serious contrast findings; exact target-state matrices remain to be completed.
**Position:** After RR09-I04 and before RR09-V01 / RR-10.
**Scope:** OT community navigation, feed/post metadata, audience control, and floating-chat label contrast in shared/app consumers.

## Finding and source owners

Prior broad axe evidence reported serious contrast findings associated with community `.nav-tab` / `.active` and post `.subtitle` text. The final I03 live diagnostic reproduced serious `color-contrast` nodes on `.subtitle`, `.active`, and `.nav-tab:nth-child(2/3)` in light mode on `/communities/create`; dark mode did not report those nodes. The source currently assigns `--local-complement` to the base navigation tab, `--local-accent` to its active state, and repeats those declarations in both `community-shell.component.scss` and `community-posts.component.scss`. The post subtitle uses `--muted-foreground` with a `#9ca3af` fallback in `libs/social-ui/src/lib/social-ui/post/post.component.scss`.

The same I03 live diagnostic found serious feed contrast nodes: `.chat-label` measured by axe at 1.14:1 in a light hover state (`#fff` on `#f2efe9`), and `#postAudience` at 3.99:1 in dark mode (`#dfdfdf` on `#6b6b6b`). The label is in `apps/client-interface/src/app/app.component.html` / `app.component.scss`; the selector is in `libs/social-ui/src/lib/social-ui/compose/compose.component.html`. These are scheduled reproduction/repair targets; verify the precise rendered state and ancestor layers before choosing a correction.
