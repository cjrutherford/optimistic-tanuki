# DF-007 J17 — Bind Presence mutations to the authenticated account

**Status: locally verified bounded Gateway Presence mutation slice.** This change binds Presence writes to the authenticated account UUID. The private authenticated HTTP/Auth/Social/database harness and independent cleanup checks passed. This is not full Gateway deployment acceptance; DF-007 and RR-11 remain open.

## Behavior

POST `/presence` takes its actor from `@User().userId`, validates it as a UUID, and overwrites the legacy body `userId` before sending Social RPC. Last-seen and offline PUT routes require the path UUID to match the authenticated account, case-insensitively, and pass the canonical account UUID to Social. A missing or malformed account identity returns 401; a different path account returns 403 before Social RPC. Read and batch routes retain their existing cross-account behavior. Selected-profile claims are not used as ownership evidence.
