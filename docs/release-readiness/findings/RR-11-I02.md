7. An approved acknowledgement/completion approach and any response times the operator can meet. No response deadline is currently supported.
8. A safe completion record and exact readback proving the promised outcome, plus negative tests for another person's data and unauthorized profile/scope access.

Do not use RR09-I04's retained synthetic global profile as a deletion test.
