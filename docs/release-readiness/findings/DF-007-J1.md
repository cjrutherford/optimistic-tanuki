# DF-007 J1 — Durable internal export jobs

**Status: locally verified internal export-job foundation.** This adds an internal job ledger around the existing partial preview. Account export/download and deletion remain unavailable. DF-007 and RR-11 remain open.

Authentication now stores account-authorized export-job status, UUID idempotency keys, attempts and DB-clock leases. Requests for one account serialize across application scopes. Repeated creation with the same account/app/key returns the existing job without running it again. A different key can start after an earlier job has finished incomplete. Fresh authorization is required for status and explicit resume; no bearer credential is stored for an unattended worker.

Claims use a unique nonce and increasing attempt. Only the current, unexpired claim may acknowledge work, and completed jobs cannot be reclaimed. Invalid preview responses and unavailable previews have separate bounded error codes. The ledger contains fixed status/coverage summaries, with no participant content or raw error text. Downloads remain disabled: the inventory is unaccepted, media portability is uncovered, and artifact URLs are always null.

The shared completeness evaluator now checks each participant against the requested account. The generated Authentication migration adds only `account_export_jobs` and its indexes. It was generated through the owning Nx target, applied after the baseline to a fresh isolated PostgreSQL database, reverted, and reapplied; governance validation passed. The ledger is additional account-associated data and remains within the future account-deletion and retention work, with no retained-data exception.
