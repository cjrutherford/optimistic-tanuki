# N04 — logging containment progress (OT/TS)

**Status: ACTIVE, not accepted.** Scope is Optimistic Tanuki (`client-interface`), Towne Square (`local-hub`) and the shared services needed by those applications. N03 remains the last accepted N slice. This is progress within the existing N04; it adds no slice IDs.

Named Gateway and Profile log producers no longer serialize authenticated users, comment DTOs, account/profile IDs or raw errors. OT socket diagnostics, HTTP-error logging and route resolvers no longer print their payloads, URLs or profile objects. TS payment diagnostics no longer print raw provider errors. Business requests, UI error presentation and broadcasts retain their existing behavior.

The existing shared logger library now provides a closed diagnostic projection. It emits an allowlisted event and bounded status/outcome/count fields, ignores raw metadata and getters, and contains sink errors. It is used by the migrated producers; it is not a global replacement for every console or Nest logger call. A permission regression exposed during verification is also repaired: an authoritative permission reply grants only when it is the literal boolean `true`; objects, strings, numbers and null deny. Four new cases failed before that correction and passed afterward.

A reusable declared-sink contract validates the supplied account/profile selection, requires an adapter's purge followed by zero readback, and blocks unsupported or unresolved shared sinks. It cannot discover a complete inventory, authorize deletion, install production adapters or finish a global deletion job. A real Nest console test excludes private sentinels. A temporary-file adapter test independently rereads the file, preserves a counterpart record and still returns incomplete when an operator sink has no adapter. These are component/contract proofs, not deployed log deletion.

## What prevents N04 acceptance

The [sink inventory](../evidence/df-007/n04-log-sink-inventory.json) is explicitly partial. The local Docker default driver is `json-file`; existing stdout/stderr, rotated files and any forwarded copies have not been purged or proven absent. No existing log payloads were inspected or deleted. Optional SSR telemetry and deployed collector routing/retention remain unverified. Additional reachable producers still require review.

Profile/Assets guardian activity, Social activity and membership/guardian/moderation audits, and Forum moderation records have no accepted immediate account purge adapters. Their participation fields use different identity domains: membership actor IDs are account UUIDs, membership subject IDs are profile UUIDs, and moderated subject IDs identify content. Matching one participant does not justify deleting an entire shared row or disclosing its private details. Existing safe export receipts are not deletion contracts.

N04 therefore remains open for a complete sink/producer inventory, historical-copy disposition, ownership-safe purge adapters and independent failure/retry/readback evidence. Full account-deletion wiring and permanent distributed fencing remain D00 and its owning adapters; rolling retention remains R2-02. No public UI, download availability, full deletion, deployed collector erasure or production qualification is claimed.
