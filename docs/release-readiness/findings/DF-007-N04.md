# N04 — local diagnostic and audit-erasure contracts (OT/TS)

**Status: VERIFIED LOCAL OT/TS, 2026-10-24.** The user approved preserving audit history while erasing the deleting account's identifying fields. Scope is `client-interface`, `local-hub` and their required shared owners. This closes the declared local N04 contract; it does not complete global account deletion or qualify deployed log copies.

The existing logger library contains the shared transactional erasure runner. Profile, Assets, Social and Forum provide eight explicit source policies. Matched account/profile identifiers and unreviewed payloads are cleared while original event IDs, timestamps and narrow action history remain. Unmatched counterpart participation and underlying profiles, assets, posts and Forum content are preserved. Social private activity facts are removed without cascading into referenced content. Active guardian asset grants remain an owner-revocation/D00 prerequisite.

The runner bounds rows and statements, locks declared tables in a fixed order, parameterizes identity values and independently checks both zero remaining identity matches and retained-row payload redaction. Historical dependent-profile links are cleared through their matching account binding. Safe export projections accept redacted counterpart context while retaining strict participant selectors. No public erasure endpoint or export-grant erasure authority was added.
