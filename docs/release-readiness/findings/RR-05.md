### Invalid attempts excluded from acceptance

The first new-spec import pulled decorator-bearing dependencies into Playwright's transform and failed before tests; importing only the actual wire command literals resolved that fixture issue. An early socket run appeared to pass because its 2.5-second negative observation ended before a roughly five-second recipient-classification lookup. Server logs exposed the later write; the corrected authorized-first probe observed the forged delivery and persistence in all projects. A preliminary expanded run used the wrong block URL and expected a membership object where the endpoint returns a boolean; those attempts are excluded. The final stable run uses the actual block route, confirms durable block state and checks boolean membership. HTTP 500 never counts as a valid privacy denial.
