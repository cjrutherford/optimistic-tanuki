# R2-01 — Rolling session inactivity

Status: **VERIFIED LOCAL**, 2026-10-27. Classification: **COMPLETE-local**.
Scope: OT `client-interface`, TS `local-hub` and their required shared services.

The owning Authentication database now enforces seven days since activity,
with the exact boundary expired and no absolute session-age cap. New OT/TS
JWTs remain signed and app-bound but have no absolute expiry. Every validation
still requires the stored unrevoked session, current identity binding and no
account deletion fence. Other products keep their previous lifetime.

The generated `1793105343107-RollingSessionActivity` migration adds nullable
`lastActivityAt`, without backfill. A legacy row starts from verified JWT `iat`;
a deployment cannot revive an ancient session. The scoped legacy-expiry fallback
verifies the signature before the database inactivity check. Inbound authenticated
HTTP and socket client activity can advance the clock; internal capture/job
validation and server pushes cannot. Cookies renew for seven days. Trusted
browser input can request `/session` renewal at most hourly, without an idle timer.

Real PostgreSQL checks passed null legacy rows, the exact cutoff, a just-live
session, concurrent activity, read-only checks, revocation, wrong bindings and
a permanent account fence. A 100-day issuance time with recent activity remained
valid. Migration up/down/reapply and migration validation passed. The owning Nx
generator also emitted equivalent existing JSON defaults; those unrelated
statements were removed before the fresh migration cycle. The generated
filename and timestamp were preserved.

The combined real-process fixture exercised both app scopes through guarded
HTTP and two Auth processes: old issued/expired legacy JWTs with recent persisted
activity, seven-day cookies, cookie/bearer compatibility, legacy inactivity and
replica revocation. Both rebuilt applications then completed real export and
account-deletion flows in system Chrome. Focused issuer, guard, controller,
Auth-state and activity-helper checks also passed.
