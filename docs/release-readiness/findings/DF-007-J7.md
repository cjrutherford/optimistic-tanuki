# DF-007 J7 — Assets snapshot identity consumer

**Status: locally verified component; complete Assets export remains open.** Assets now has a client for traversing J6's fenced Profile identity pages. It is not registered in the module or called by a route or export participant yet. No Assets database, media bytes, artifact, download or deletion is enabled by this component. Item 1, DF-007 and RR-11 remain open.

The client copies grant and capture metadata before awaiting responses. Every page must match the account, handle, capture, exact timestamp text, total count, expected page length and next offset. IDs must be lowercase UUID strings in strictly increasing order across page boundaries; the database-valid all-zero UUID is accepted. An empty capture still requires one successful empty-page response. Validated page arrays are frozen and passed to the consumer without accumulating the account's full identity list.

Reads use J6's existing internal identity command. Profile remains responsible for session and job-lease authorization. Requests time out after three seconds; the operation has a two-minute deadline and accepts caller cancellation. The client passes a combined abort signal to downstream callbacks. It cannot prove cancellation of work that ignores that signal. Transport and callback errors become stable codes without their private details.

The focused Nx suite passed **19 tests** with simulated RPC responses: 1,006 identities across eleven pages, empty capture, zero UUID, mismatched metadata, duplicate/out-of-order IDs, malformed rows, missing/extra rows, invalid cursors, failure-detail suppression, cancellation, deadline and input mutation. Parent review added a regression for nested arrays that JavaScript's UUID regex could otherwise coerce to a string. Assets production build and lint passed through the checked-in Nx targets. Scoped formatting passed. See the [receipt](../evidence/df-007/checkpoint-j7.json).

This component has no actual Assets RPC, database or media integration proof. J6's separate live-service evidence is unchanged.
