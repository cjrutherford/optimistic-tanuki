# DF-007 O09 — OT/TS Classifieds account-data capture

Date: 2026-10-23. **O09-P, O09-C and O09-I locally verified.** Release scope is only Optimistic Tanuki (`client-interface`) and Towne Square (`local-hub`). No other product is counted or qualified.

Towne Square's city/community Classifieds pages use shared `classified-ui`, the Gateway and Classifieds service. No OT Classifieds UI consumer has been established. The capture accepts only the two explicit stored app scopes, requires the authenticated account, and proves each candidate profile against the captured Profile identities. A scoped account-owned row with an unproven profile binding blocks capture. Other-product rows are excluded even when the account owns them; foreign-account rows are excluded even when their profile field names an owned profile.

The safe projection retains seventeen fields, bounded inert authored text, exact decimal prices, historical listing states, optional timestamps and opaque community references. Raw image URLs are never read into capture. Attribution remains recorded/unverified and consent is not inferred. See the [field/store policy](../CLASSIFIEDS-DISPOSITIONS.md).
